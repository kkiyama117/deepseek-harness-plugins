### Rules

1. **Start a child with SIGINT blocked.** In `run_child`, call `signal.pthread_sigmask(signal.SIG_BLOCK, {signal.SIGINT})` right before `subprocess.Popen`, and keep the returned old mask. Assign the `Popen` result to `proc` inside the `try` that handles `KeyboardInterrupt` (initialize `proc = None` before it). The first statement after the assignment, still inside that `try`, restores the old mask with `signal.pthread_sigmask(signal.SIG_SETMASK, <old mask>)`; a SIGINT that arrived while blocked is delivered there, so the existing `KeyboardInterrupt` handler kills the process group. The handler kills only when `proc` is not `None`. When `Popen` raises `OSError`, restore the old mask before returning T40's cannot-start result. The child inherits the blocked mask; that is harmless because it runs in its own session and is stopped with `SIGKILL`.

2. **Block SIGINT once the status is decided.** In `Apply.run`, as the last statement inside the outer `try` (after `status, code` is assigned from `steps()` or from `abort`), and as the first statement of the `except KeyboardInterrupt` handler, call `signal.pthread_sigmask(signal.SIG_BLOCK, {signal.SIGINT})`. SIGINT then stays blocked until the script exits (`emit` included), so a SIGINT after the status is decided is dropped, and a second SIGINT during the interrupt handling is held too. The `try`/`except KeyboardInterrupt` around the `LIVE_APPLY_CHECK_SERVICE` lines is removed, because SIGINT is already blocked there.

3. **No temporary file left after a failed replace.** In `replace_target`, when anything after the temporary file was created raises `OSError` (the writes, `os.fchmod`, `os.close`, or `os.replace`), remove the temporary file (`unlink(missing_ok=True)`, ignoring an `OSError`) before raising the `LiveApplyError`. This holds for the write of step 6 and for every restore.

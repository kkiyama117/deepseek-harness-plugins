### Rules

1. **Start a child with SIGINT blocked.** In `run_child`, call `signal.pthread_sigmask(signal.SIG_BLOCK, {signal.SIGINT})` right before `subprocess.Popen`, and keep the returned old mask. Inside the `try` that handles `KeyboardInterrupt` (with `proc = None` set before it), an inner `try` assigns the `Popen` result to `proc`, has the existing `except OSError` (T40's cannot-start result), and has a `finally` that restores the old mask with `signal.pthread_sigmask(signal.SIG_SETMASK, <old mask>)` whatever happened. A SIGINT that arrived while blocked is delivered at that restore, still inside the outer `try`, so the existing `KeyboardInterrupt` handler runs, and kills the process group when `proc` is set. When `proc` is `None`, the handler skips both the kill and the `communicate(timeout=10)` wait and re-raises at once. In this script SIGINT is never blocked when `run_child` starts (rule 2 blocks it only after the last child has ended), so the old mask never contains SIGINT; a caller that starts the script with SIGINT already blocked is out of scope. A failure of `signal.pthread_sigmask` itself (it raises only for invalid arguments) is out of scope. The child inherits the blocked mask; that is harmless because it runs in its own session and is stopped with `SIGKILL`.

2. **Block SIGINT once the status is decided.** In `Apply.run`, as the last statement inside the outer `try` (after `status, code` is assigned from `steps()` or from `abort`), and as the first statement of the `except KeyboardInterrupt` handler, call `signal.pthread_sigmask(signal.SIG_BLOCK, {signal.SIGINT})`. SIGINT then stays blocked until the script exits (`emit` included), so a SIGINT after the status is decided is dropped, and a second SIGINT during the interrupt handling is held too. A SIGINT in the one statement between `steps()` returning and the block call is handled by T41 rule 2 (the target is restored and the exit is 130), and a second SIGINT in the one statement between entering the handler and its block call propagates; both windows are accepted. A second SIGINT while `run_child`'s own `KeyboardInterrupt` handler kills and waits propagates to this handler, which blocks first; that is accepted too. This rule replaces T41 rule 10's sentence about a `KeyboardInterrupt` while printing the service lines: SIGINT is blocked there now. The `try`/`except KeyboardInterrupt` around the `LIVE_APPLY_CHECK_SERVICE` lines is removed, because SIGINT is already blocked there.

3. **Remove the temporary file after a failed replace.** In `replace_target`, when anything after the temporary file was created raises `OSError` (the writes, `os.fchmod`, `os.close`, or `os.replace`), remove the temporary file (`unlink(missing_ok=True)`, ignoring an `OSError`) before raising the `LiveApplyError`. This holds for the write of step 6 and for every restore. If that removal itself fails, the file stays; that is accepted. When a write fails and the following `os.close` fails too, the `LiveApplyError` carries the write's error, and the close's error is dropped. A failure of the leading `unlink(missing_ok=True)`, before this run created anything, needs no cleanup.

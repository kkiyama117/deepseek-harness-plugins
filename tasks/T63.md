### Rules

1. `index.mjs` is plain ESM with no imports. It exports exactly: `name = 'sandbox-facts'`, `inject = ['tools']`, `factsLine(exec, result)`, `createListener(write, warn)`, and `apply(ctx)`.
2. `factsLine(exec, result)` returns a string or `undefined`, never throws for any input (including `undefined`, `null`, or a non-object for either argument), and never changes its arguments. It returns `undefined` unless all of these hold:
   - `exec` is an object, `exec.name === 'bash'`, and `typeof exec.callId === 'string'`;
   - `result` is an object, `result.isError === false`, and `result.value` is an object whose `sandbox` is a non-null object, not an array;
   - `typeof sandbox.mode === 'string'` and `typeof sandbox.denied === 'boolean'`;
   - `sandbox.enforcement` is absent (`undefined`), `'full'`, or `'partial'`;
   - `sandbox.runnerFailed` is absent (`undefined`) or a boolean.

   Otherwise it returns `JSON.stringify({ type: 'tool_facts', callId: exec.callId, tool: 'bash', sandbox: { mode, denied, enforcement, runnerFailed } }) + '\n'`, with the keys in exactly that order, where `mode` and `denied` are copied as given, `enforcement` is the value's `enforcement` or `null` when absent, and `runnerFailed` is `sandbox.runnerFailed === true`. No other field of `exec` or `result` (arguments, stdout, stderr, cwd, content) appears in the line.
3. `createListener(write, warn)` returns `(exec, result) => undefined`. The listener calls `factsLine`; when it returns a string, it calls `write(line)` exactly once with the whole line (one call per line, never split). When it returns `undefined`, it calls neither `write` nor `warn`. If `write` throws, the listener catches it, calls `warn` once with a message that starts with `sandbox-facts: write failed for ` followed by the `callId`, and returns normally. If `warn` itself throws, that is caught too. The listener never throws and never returns a promise.
4. `apply(ctx)` registers exactly one listener: `ctx.on('tools/result', createListener(chunk => process.stdout.write(chunk), message => ctx.logger.warn(message)))`. It registers nothing else and writes nothing at load time.
5. `locale/en.json`: `{"meta":{"title":"Sandbox facts","description":"Write each bash call's sandbox facts as one tool_facts line on stdout for headless --json runs."}}`. `locale/ja.json`: `{"meta":{"title":"Sandbox facts","description":"headless --json の実行で、bash の各呼び出しの sandbox の事実を tool_facts の 1 行として stdout に出力します。"}}`. Both pretty-printed with two spaces and a final newline, like `plugins/dsh-codex-transport-recovery/locale/en.json`.

### Tests

All in `tests/sandbox-facts.test.mjs`, `node:test` and `node:assert/strict`, synthetic values only, no file system, no network, no `process.stdout` writes (tests use `createListener` with a collecting `write`, or `factsLine`). `bash(sandbox)` below means `{ name: 'bash', callId: 'call-1' }` and `{ isError: false, value: { kind: 'foreground', cwd: '/w', exitCode: 0, signal: null, timedOut: false, aborted: false, timeoutMs: 1000, stdout: { text: 'secret-out', truncated: false }, stderr: { text: '', truncated: false }, sandbox }, content: [] }`, built with `Object.freeze` deeply.

| Test | Steps | Assert |
|---|---|---|
| `writes partial enforcement into the tool_facts line` | listener with a collecting `write`; call it with `bash({ mode: 'workspace-write', denied: false, enforcement: 'partial' })` | exactly one write; the chunk equals `'{"type":"tool_facts","callId":"call-1","tool":"bash","sandbox":{"mode":"workspace-write","denied":false,"enforcement":"partial","runnerFailed":false}}\n'` |
| `writes runnerFailed true and denied true as given` | `bash({ mode: 'read-only', denied: true, enforcement: 'full', runnerFailed: true })` | parsed line's `sandbox` deep-equals `{ mode: 'read-only', denied: true, enforcement: 'full', runnerFailed: true }` |
| `writes enforcement null when the value has none` | `bash({ mode: 'danger-full-access', denied: false })` | parsed `sandbox.enforcement` is `null`; `Object.keys(parsed.sandbox)` equals `['mode', 'denied', 'enforcement', 'runnerFailed']` |
| `writes runnerFailed false when the value has none` | `bash({ mode: 'workspace-write', denied: false, enforcement: 'full' })` | parsed `sandbox.runnerFailed` is `false` |
| `writes nothing for a background handle` | bash exec; result `{ isError: false, value: { kind: 'background', jobId: 'j1', cwd: '/w' }, content: [] }` | no write, no warn |
| `writes nothing for a value without sandbox` | `bash(...)` value with the `sandbox` key removed | no write, no warn, the call does not throw |
| `writes nothing for a failed call` | bash exec; `{ isError: true, error: { message: 'sandbox runner failed' }, content: [] }` | no write |
| `writes nothing for another tool` | exec `{ name: 'read', callId: 'call-2' }` with the `bash({ mode: 'workspace-write', denied: false })` result | no write |
| `writes nothing for unexpected sandbox field types` | one call each with sandbox `{ mode: 1, denied: false }`, `{ mode: 'x', denied: 'no' }`, `{ mode: 'x', denied: false, enforcement: 'none' }`, `{ mode: 'x', denied: false, runnerFailed: 'yes' }`, `null`, `[]`; plus `factsLine(undefined, undefined)` and `factsLine(null, 'x')` | no write for any; each `factsLine` returns `undefined` without throwing |
| `writes one valid JSON line per call without leaking output` | three bash calls with callIds `a`, `b`, `c` | three writes; each chunk ends with exactly one `\n` and has no other `\n`; `JSON.parse` of each succeeds; callIds are `['a', 'b', 'c']` in call order; no chunk contains `secret-out`; the frozen inputs are unchanged |
| `contains a failing write and warns` | `write` throws `new Error('EPIPE')`; collecting `warn` | the listener returns `undefined` without throwing; one warn whose message starts with `sandbox-facts: write failed for call-1` |
| `contains a failing warn` | `write` and `warn` both throw | the listener returns `undefined` without throwing |
| `registers one tools/result listener and writes nothing at load` | fake `ctx` `{ on(event, cb) {...}, logger: { warn() {} } }`; `apply(ctx)` | `on` called once with `'tools/result'` and a function; `name === 'sandbox-facts'`; `inject` deep-equals `['tools']` |

Must fail without: the `enforcement` value check in `factsLine` (rule 2, fourth bullet) → `writes nothing for unexpected sandbox field types`.

Must fail without: the `try`/`catch` around `write` in the listener (rule 3) → `contains a failing write and warns`.

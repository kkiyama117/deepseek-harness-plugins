Read-only, for the record shapes: `/data/softwares/kstack/docs/contracts/acceptance.md` sections 4.2 (`gate.json`), 4.4 (`review-<seq>.json`) and 8 (dispatcher duties), and in `/data/softwares/kstack/bin/kstack-accept` the functions `load_gate` and `load_runs` (the reader these records must satisfy). ### Rules

1. New module names in `bin/dispatch.py`:
   - `import socket`.
   - `ACCEPT = KSTACK / 'bin/kstack-accept'`.
   - `REVIEW_KINDS = ('round', 'fixcheck', 'supplement', 'optional')`.
   - `GATE_SCHEMA = 'kstack-accept/gate/1'` and `REVIEW_SCHEMA = 'kstack-accept/review/1'`.
   - `FINDING = re.compile(r'^(?P<loc>[^|]+?)\s*\|\s*(?P<sev>high|medium|low)\s*\|', re.IGNORECASE)` and `FENCE = re.compile(r'^\s*(```|~~~)')`.
2. `evidence_dir(main, card_id)` returns `Path(main) / 'reports/agents/evidence' / card_id`. `write_evidence(main, card_id, name, text)` writes `text` (UTF-8) to `evidence_dir(main, card_id) / name` exactly as `write_scope` writes `scope.json` today (missing directories created, a unique temporary file from `tempfile.mkstemp(prefix=f'.{name}.', suffix='.tmp', dir=<that directory>)`, so no temporary name starts with `review-`, `os.replace`, the temporary file removed on `OSError`, other files untouched) and returns the path. `write_scope(main, card_id, record)` keeps its signature and behavior and calls `write_evidence(main, card_id, 'scope.json', json.dumps(record, indent=2) + '\n')`. `gate.json`, `gate.log` and every `review-<seq>.json` are written only through `write_evidence`; JSON records use `json.dumps(record, indent=2) + '\n'`.
3. `read_scope(main, card_id)` reads `evidence_dir(main, card_id) / 'scope.json'`. When the file does not exist it raises `DispatchError(f'no scope.json for {card_id}; run card first')`. When it is not valid JSON, not an object, or its `repos` is not a non-empty list of objects that each have string `name`, `path` and `base`, it raises `DispatchError(f'bad scope.json for {card_id}')`. Otherwise it returns the dict.
4. `work_state(path)` runs `[str(ACCEPT), 'state', str(path)]` (capture output, text). It returns the stripped stdout. When the exit is not 0 or the stdout is empty, it raises `DispatchError(f'kstack-accept state failed for {path}: {stderr stripped}')`.
5. `runtime_rev()`:
   1. The CLI is `os.environ['DSH_CLI']` when that is set and not empty, else `shutil.which('dsh')`. With neither, return `'unknown'`.
   2. Resolve it with `Path(...).resolve()`. Starting at its parent directory, walk up until a directory holds an entry named `.git` (a file or a directory). If the walk reaches the filesystem root without one, return `'unknown'`.
   3. Return `git rev-parse HEAD` run there, plus `'-dirty'` when `git status --porcelain` there prints anything. If either git call fails, return `'unknown'`.
6. `worker_command(worker, workdir, route, read_only)` returns `[str(worker), *(['--read-only'] if read_only else []), str(workdir), *route]`. `run_worker` builds its command with it, and gains a keyword `env=None` that it passes to `subprocess.run`. Its return value and every other behavior stay the same.
7. `gate_step(main, root, card_id, worktree, branch)` runs the full gate for a card and records it:
   1. `scope = read_scope(main, card_id)`.
   2. For each entry of `scope['repos']`, in order: `new = git('merge-base', f'card/{card_id}', branch, cwd=entry['path'])` stripped. When it differs from `entry['base']`, print `base {entry["name"]} {old} -> {new}` and set it. When at least one base changed, `write_scope(main, card_id, scope)` once; an `OSError` from it raises `DispatchError(f'cannot write scope.json: {error}')`, and the gate does not run.
   3. `states = {entry['name']: work_state(entry['path'])}` for every entry of `scope['repos']` and then of `scope.get('gate_repos') or []`.
   4. `started` is `datetime.now(timezone.utc).strftime('%Y%m%dT%H%M%SZ')`. Run `GATE` with `shell=True`, `cwd=worktree`, stdout to a pipe and stderr into stdout, `text=True`, `errors='replace'`. `ended` is taken the same way after it ends.
   5. `write_evidence(main, card_id, 'gate.log', <the gate output>)`, then `write_evidence(main, card_id, 'gate.json', ...)` with this record, keys in this order: `'schema': GATE_SCHEMA`, `'command': GATE`, `'cwd': str(worktree)`, `'exit': <the gate exit code>`, `'started_utc': started`, `'ended_utc': ended`, `'log': 'gate.log'`, `'states': states`.
   6. Print `gate exit {code}` and `gate.json {path}`, and return `(code, tail)`, where `tail` is the last 40 lines of the output joined by `'\n'`, or `'(no output)'` when there are none.
8. New verb `gate ID` (`verbs.add_parser('gate', help='refresh the base, run the full gate, and write gate.json')`, one positional `id`, checked by `_check_ids` like `land`). `_gate(args, root)`:
   1. `branch = issue_branch(root)`; `main = main_checkout(root)`; `find_card(root, args.id)` (it must exist); the worktree is `_worktree(main, args.id)`, and when it is not a directory raise `DispatchError(f'no worktree {worktree}')`.
   2. `read_scope(main, args.id)` (so a missing scope.json refuses before anything runs).
   3. When `worktree / 'bin/gate.py'` is not a file, raise `DispatchError(f'no bin/gate.py in {worktree}')`.
   4. When `_status_paths(worktree)` is not empty, print `warning: the worktree has uncommitted changes; gate.json holds their state, so commit exactly this tree`.
   5. Run `gate_step(main, root, args.id, worktree, branch)` and return its exit code.
9. `review ID` gains `--kind`, with `choices=REVIEW_KINDS` and `default='round'`. `--main` mode is unchanged, writes no record, and ignores `--kind`. In worktree mode, `_review` does this, in this order:
   1. As now: `branch`, `card`, `main`, and the worktree check. Then, as `_land` does, when the worktree's `git symbolic-ref --quiet --short HEAD` fails or is not `card/{card.id}`, raise `DispatchError(f'the worktree is not on card/{card.id}')`. So the diff's `git merge-base HEAD {branch}` (rule 9.7) equals the scope base that the gate step refreshes.
   2. `scope = read_scope(main, card.id)`.
   3. History: read every file `evidence_dir / f'review-{n}.json'` whose name matches `^review-([0-9]+)\.json$`. A file raises `DispatchError(f'bad review record {path}')` when it is not valid JSON, not an object, its `seq` is not the integer `n`, its `kind` is not in `REVIEW_KINDS`, or, for kind `round` or `fixcheck`, its `state` is not an object, or, for kind `round`, its `round` is not an integer of at least 1. The records whose `kind` is `'round'` or `'fixcheck'` are the history, in order of `n`; `optional` and `supplement` records are not. `latest` is the last of them, or `None`.
   4. `seq` is 1 + the highest `n` over every entry of the evidence directory whose name matches `^review-([0-9]+)\.`, or 1 when there is none (so a leftover `review-4.events.jsonl` makes the next seq 5).
   5. When `args.kind` is `fixcheck` or `supplement` and `latest` is `None`, raise `DispatchError(f'review --kind {args.kind} needs an earlier round or fixcheck')`.
   6. Gate. When `worktree / 'bin/gate.py'` is not a file: print `gate skipped: no bin/gate.py` and use the existing `NO_GATE_BLOCK` (no gate.json is read or written); there is no gate code, and the nonzero check below is skipped. Otherwise compute the current states as in rule 7.3 (without refreshing any base). When `gate.json` and `gate.log` both exist in the evidence directory, `gate.json` is valid JSON with an integer `exit`, and its `states` equals the current states: print `gate reused gate.json (exit {exit})`, and take `code` from it and the tail from `gate.log` (its last 40 lines joined by `'\n'`, or `'(no output)'` when it has none). Otherwise `code, tail = gate_step(main, root, card.id, worktree, branch)`. When `code` is not 0, raise `DispatchError(f'the gate exited {code}; the review does not start')`. When `code` is 0, the brief's gate block is `GATE_BLOCK` with that code and tail.
   7. The diff, untracked list and brief are built as now, after the gate step (so a refreshed base is in place).
   8. `state = {entry['name']: work_state(entry['path']) for entry in scope['repos']}`.
   9. `round`: for kind `round`, `latest_round = ` the last history record whose kind is `round`; the round is `latest_round['round']` when `latest_round` exists and its `state` equals `state`, else 1 + the highest `round` among the history's `round` records (1 when there is none). For every other kind it is `None`. `covers` is `latest['seq']` (equal to its file number) for `supplement`, else `None`. `covers_from` is `latest['state']` for `fixcheck`, else `None`.
   10. `events = evidence_dir(main, card.id) / f'review-{seq}.events.jsonl'`; create the evidence directory if missing. `argv = worker_command(worker, worktree, REVIEW_ROUTE, True)`. Run `code, answer = run_worker(main / 'reports/agents', f'review-{card.id}', worktree, REVIEW_ROUTE, brief, read_only=True, worker=worker, env={**os.environ, 'RUN_WORKER_EVENTS': str(events)})`. The `.log` path is the answer path with suffix `.log`.
   11. When a line of the `.log` starts with `run-worker.sh: RUN_WORKER_EVENTS `, print `no review record: the wrapper refused the events file`, write no record, and return the worker's exit code.
   12. `state_after` as in step 8. `kind = args.kind`. When the worker's exit is not 0 and `kind` is not `optional`: print `review-{seq}.json written as optional: the reviewer exited {code}`, and set `kind = 'optional'`, `round`, `covers` and `covers_from` to `None`. For kind `optional` from `--kind`, `round`, `covers` and `covers_from` are `None` too.
   13. `rev = runtime_rev()`; when it is `'unknown'`, print `warning: runtime revision unknown`. Write `review-{seq}.json` with this record, keys in this order: `'schema': REVIEW_SCHEMA`, `'seq': seq`, `'kind': kind`, `'round': round`, `'covers': covers`, `'argv': argv`, `'exit': code` (the reviewer's exit from step 10, not the gate's), `'answer': str(answer)`, `'events': str(events)`, `'stderr': str(log)`, `'runtime_rev': rev`, `'host': socket.gethostname()`, `'lineage': implementer_lineage(REVIEW_ROUTE)`, `'state': state`, `'state_after': state_after`, `'covers_from': covers_from`. Print `review-{seq}.json {path}`.
   14. Read the answer. Outside fenced blocks (a line matching `FENCE` toggles a fence and is never a finding), number the lines that match `FINDING` from 1 and print `finding {seq}.{k} {line}` for each. Return the worker's exit code.
10. In `REVIEW_BRIEF` (not `MAIN_REVIEW_BRIEF`), right after the sentence `Do not run any command that builds or tests code: you run read-only.`, insert one space and this sentence: `Run one bash command, \`pwd\`, before anything else; the sandbox evidence needs at least one bash call.` (with real backticks around `pwd`).
11. Module docstring: in the usage block add the line `    python3 bin/dispatch.py gate ID` after the `card` line, and change the `review` line to `    python3 bin/dispatch.py review ID [--kind KIND] [--main PATH ...]`. Replace the words `Every verb except \`card\` starts its worker with \`--read-only\`` with `Every verb that starts a worker, except \`card\`, starts it with \`--read-only\`` (the rest of that sentence and paragraph unchanged). Then add this paragraph after the paragraph that starts `` `card` also writes ``:

### Rules

1. Add these module constants to `bin/dispatch.py`, next to `WORKER_ROUTE`:
   - `TIERS = ('R0', 'R1', 'R1s', 'R2')`
   - `LINEAGE = {'deepseek-v4.1-flash': 'deepseek', 'gpt-6.1-sol': 'openai'}`
   - `SCOPE_SCHEMA = 'kstack-accept/scope/1'`
   - `LAND_REPO = 'deepseek-harness-plugins'`
2. `card_tier(card)` takes a `Card` and reads `card.text`. It finds the first line that starts with `Tier:`. With no such line it raises `DispatchError(f'card {card.id}: no Tier: line; declare one of R0, R1, R1s, R2')`; there is no default tier. Otherwise the tier is the first whitespace-separated word after `Tier:`, or `''` when there is none. A tier in `TIERS` is returned. Any other tier, `''` included, raises `DispatchError(f'card {card.id}: unknown tier "{tier}"; declare one of R0, R1, R1s, R2')`. The comparison is exact and case-sensitive. In both messages the list is `', '.join(TIERS)`. The tier is only ever read from the card; nothing derives it from the diff, the files, or the route.
3. `implementer_lineage(route)` returns `LINEAGE[route[2]]`. When `route[2]` is not a key of `LINEAGE`, it raises `DispatchError(f'no implementer lineage for {route[2]}')`.
4. `scope_record(root, card, worktree, branch, tier, lineage)` returns this dict, with the keys in this order:
   - `'schema'`: `SCOPE_SCHEMA`
   - `'card'`: `card.id`
   - `'card_file'`: `str(Path(root) / 'tasks' / f'{card.id}.md')`, the card in the issue worktree, not the copy in the card worktree
   - `'tier'`: `tier`
   - `'implementer_lineage'`: `lineage`
   - `'repos'`: `[{'name': LAND_REPO, 'path': str(worktree), 'base': base}]`, keys in that order, where `base` is the stripped stdout of `git('merge-base', f'card/{card.id}', branch, cwd=root)`. Only the land repo: this dispatcher makes worktrees in one repository, and `<repo>:<path>` spans in `Files:` are not read.
   - `'gate_repos'`: `[]` always. This dispatcher writes no `gate.json`; listing gate repos belongs to a later `gate` verb.
   - `'degraded'`: `False`
   - `'degraded_reason'`: `''`
5. `write_scope(main, card_id, record)` writes `json.dumps(record, indent=2) + '\n'` (UTF-8) to `Path(main) / 'reports/agents/evidence' / card_id / 'scope.json'` and returns that path. It creates the missing directories. It writes a temporary file in the same directory and moves it over `scope.json` with `os.replace`, called as `os.replace` on the module `os` (`import os` in `bin/dispatch.py`) so that a test can patch it, so an existing `scope.json` is replaced and never truncated in place; the temporary file is removed when the write fails. Every other file in that directory is kept unchanged.
6. In `_card`, keep every existing check and its order. After the check that `card/<id>` does not exist and before the `uncommitted changes` warning:
   1. `tier = card_tier(card)`.
   2. `lineage = implementer_lineage(WORKER_ROUTE)`.

   A `DispatchError` from either ends the verb with exit 2, as every `DispatchError` does, before any worktree, branch, or directory is made and before any worker runs.
7. In `_card`, right after `git worktree add` succeeds and before the `worktree` line is printed:
   1. Call `scope_record(root, card, worktree, branch, tier, lineage)` and `write_scope(main, card.id, record)`. When either raises `OSError` or `DispatchError`, call `_discard_worktree(root, worktree, card_branch)` and raise `DispatchError(f'cannot write scope.json: {error}')`, so no worker runs.
   2. The existing output lines follow, with one new line after `land {branch}`: `scope {path}`, where `path` is what `write_scope` returned.

   This happens with and without `--no-worker`.
8. Add to the module docstring of `bin/dispatch.py`, as a new paragraph after the one that starts `Every verb except`: ``card` also writes `reports/agents/evidence/<ID>/scope.json` of the main checkout for kstack-accept, before the worker starts: the tier from the card's `Tier:` line (a card without a valid one is refused before the worktree is made), the implementer lineage of the worker's model, the card worktree, and its base, the merge base of `card/<ID>` and the issue branch. Workers never read or write that directory.`
9. `AGENTS.md`, section `Card-flow adapter`, the `Dispatcher` bullet: after the sentence `Worker answers and logs go to `reports/agents/<UTC>-<kind>.md` and `.log`.` insert this sentence: ``card` also writes kstack-accept's scope record, `reports/agents/evidence/T<n>/scope.json` (kstack `docs/contracts/acceptance.md` section 4.1), with the tier from the card's `Tier:` line and `base` the merge base of `card/T<n>` and the issue branch; workers never read it.` Change nothing else in `AGENTS.md`.
10. `tasks/README.md`: in the card format block, insert the two lines `Tier: <R0, R1, R1s, or R2>.` and an empty line right after the `Issue: #<N>.` line and its empty line. In the bullet list under the block, after the `Issue:` bullet, add this bullet: `- `Tier:` declares the card's tier from kstack's acceptance contract (`/data/softwares/kstack/docs/contracts/acceptance.md` section 1): `R0` none of the others, `R1` a contract, migration, or data shape that another repository uses, `R1s` security, privacy routing, credentials, or the sandbox, `R2` production, irreversible, or sends data outside. The lead declares it; `dispatch.py card` copies it into `scope.json` and never derives it. A card without it, or with any other value, is refused by `dispatch.py card` before the worktree is made.` Change nothing else in `tasks/README.md`.

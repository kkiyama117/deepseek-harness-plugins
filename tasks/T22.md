## T22. pi-ai server error recovery: reclassify status-text 5xx failures as SERVER

Issue: #53.

### Rules

`index.mjs` is plain ESM with no imports, and exports exactly:

- `name`: the string `'pi-ai-server-recovery'`.
- `inject`: the array `['llm']`.
- `STATUS_TEXT`: the regular expression `/\b(?:internal server error|bad gateway|service unavailable|servers are currently overloaded)\b/i`.
- `classifyStream(chunks)`: an async generator over the async or sync iterable `chunks`. For each chunk:
  - When all of these hold: `chunk.type === 'finish'`, `chunk.reason?.kind === 'error'`, `chunk.reason.failure?.code === 'PI_AI_ERROR'`, `typeof chunk.reason.failure.message === 'string'`, and `STATUS_TEXT.test(chunk.reason.failure.message)`: yield a new object `{ ...chunk, reason: { ...chunk.reason, failure: { ...chunk.reason.failure, code: 'SERVER' } } }`.
  - Otherwise yield the same chunk object, unchanged.
  - Never mutate an input chunk or any object inside it.
- `apply(ctx)`: register exactly one listener with `ctx.on('llm/stream', (options, next) => classifyStream(next()))`. Do not read or change `options`, and call `next()` exactly once per request.

### Tests

`tests/recovery.test.mjs` uses `node:test` and `node:assert/strict` and imports `{ apply, classifyStream }` from `../index.mjs`, as the model test does. Helpers: `failure(message, code = 'PI_AI_ERROR')` returns `{ type: 'finish', reason: { kind: 'error', failure: { message, code, requestId: 'preserved' } } }`; `collect(chunks)` returns `Array.fromAsync(classifyStream(chunks))`.

| Test | Steps | Assert |
|---|---|---|
| `corrects <phrase> while preserving content, message and request id`, one test per phrase: `Internal Server Error`, `Bad Gateway`, `Service Unavailable`, `servers are currently overloaded` (the test name holds the phrase as written here) | `collect([partial, original])` with a frozen `partial = { type: 'text-delta', index: 0, text: 'unfinished' }` and `original = failure(<phrase>)`. | `result[0]` is `partial` (same object); `result[1].reason.failure.code === 'SERVER'`; its `message` is the phrase and its `requestId` is `'preserved'`; `original.reason.failure.code` is still `'PI_AI_ERROR'`. |
| `matches the phrase case-insensitively inside a longer message` | `failure('upstream said: INTERNAL SERVER ERROR (try again)')`. | The result's code is `SERVER`. |
| `leaves <label> unchanged`, one test per row below | `collect([chunk])`. | `result[0]` is `chunk` (same object). |

The `leaves <label> unchanged` rows (label → chunk):

- `unknown provider error` → `failure('Something else')`
- `authentication` → `failure('Internal Server Error', 'AUTH')`
- `already classified` → `failure('500 Internal Server Error', 'SERVER')`
- `a phrase inside a word` → `failure('xInternal Server Errorx')`
- `a non-string message` → `{ type: 'finish', reason: { kind: 'error', failure: { message: { text: 'Internal Server Error' }, code: 'PI_AI_ERROR' } } }`
- `successful completion` → `{ type: 'finish', reason: { kind: 'stop' } }`
- `cancellation` → `{ type: 'finish', reason: { kind: 'aborted', failure: { message: 'Internal Server Error', code: 'ABORTED' } } }`
- `a text delta` → `{ type: 'text-delta', index: 0, text: 'Internal Server Error' }`
- `a gateway timeout` → `failure('Gateway Timeout')` (pi-ai already maps it to `TIMEOUT`; the plugin leaves it alone)

| Test | Steps | Assert |
|---|---|---|
| `uses one official event registration and delegates the original request once` | Call `apply` with a fake `ctx` whose `on(event, callback)` records the callback and asserts `event === 'llm/stream'`. Call the callback with a frozen `options = { provider: 'ollama-cloud', model: 'deepseek-v4.1-flash' }` and a `next` that counts calls and returns the array `[failure('Internal Server Error')]` (as the model test does; `classifyStream` accepts sync iterables), and consume the returned async iterable with `await Array.fromAsync(...)`. | `on` was called once; `next` was called once; the result's code is `SERVER`; `options.model` is unchanged. |

## T70. dispatch.py: ambiguity and review --main refuse the main checkout and card worktrees

Issue: #97.

Tier: R1s

Needs: T69 (merged).

Spec: the Rules and Tests below are the full spec. Why: `ambiguity` and `review --main` pass the directory the dispatcher runs from (`root`) to the read-only worker as its workdir, and they never call `issue_branch(root)`. Run from the main checkout, the worker's workdir would be the main checkout, below which lie ignored folders that must never reach a model; the never-read fence in the brief is text only. Every other verb already refuses such a checkout through `issue_branch(root)`. Code to change: `_ambiguity` and `_review` in `bin/dispatch.py`; tests in `bin/test_dispatch.py`.

Files: `bin/dispatch.py`, `bin/test_dispatch.py`.

### Rules

1. `_ambiguity(args, root, worker)` calls `issue_branch(root)` as its first statement, before reading any card, so a checkout that is detached, on `main`, or on a `card/` branch is refused with `issue_branch`'s existing errors (exit 2) and no worker starts.
2. `_review(args, root, worker)` calls `branch = issue_branch(root)` as its first statement, before `main_checkout` and before the `--main` branch, so `review --main` is refused the same way. The worktree mode keeps using that `branch`; its own later `branch = issue_branch(root)` line goes away. Nothing else in either function changes.
3. The error messages are `issue_branch`'s, unchanged: `the checkout is on main; run the dispatcher from the issue worktree`, `the checkout is a card worktree; run the dispatcher from the issue worktree`, and `the checkout is not on a branch`.

### Tests

All in `bin/test_dispatch.py`, class `DispatchTest`, with the existing helpers. Every existing test keeps passing unchanged. Each test below makes sure that, without the fix, a worker would start: the card file exists in the checkout the dispatcher runs from, and for `review --main` that file has an uncommitted change.

| Test | Steps | Assert |
|---|---|---|
| `test_ambiguity_refuses_main` | `git('switch', 'main', cwd=self.root)`; write `CARD_T1` to `self.root / 'tasks/T1.md'` (untracked on `main`); `invoke('ambiguity', 'T1')` | exit 2; stderr has `the checkout is on main; run the dispatcher from the issue worktree`; `self.runs() == 0`; `self.root / 'reports/agents'` has no `*.md` file |
| `test_review_main_refuses_main` | `git('switch', 'main', cwd=self.root)`; write `CARD_T1` to `self.root / 'tasks/T1.md'`; `invoke('review', 'T1', '--main', 'tasks/T1.md')` | exit 2; stderr has `the checkout is on main; run the dispatcher from the issue worktree`; `self.runs() == 0` |
| `test_ambiguity_refuses_a_card_worktree` | `invoke('card', 'T1', '--no-worker')`; `invoke('ambiguity', 'T1', root=self.worktree)` | exit 2; stderr has `the checkout is a card worktree; run the dispatcher from the issue worktree`; `self.runs() == 0` |
| `test_review_main_refuses_a_card_worktree` | `invoke('card', 'T1', '--no-worker')`; write `CARD_T1 + '\nLead change.\n'` to `self.worktree / 'tasks/T1.md'`; `invoke('review', 'T1', '--main', 'tasks/T1.md', root=self.worktree)` | exit 2; stderr has `the checkout is a card worktree; run the dispatcher from the issue worktree`; `self.runs() == 0` |

Must fail without: the `issue_branch(root)` call at the start of `_ambiguity` (rule 1) → `test_ambiguity_refuses_main`, `test_ambiguity_refuses_a_card_worktree`.

Must fail without: the `issue_branch(root)` call at the start of `_review` before the `--main` branch (rule 2) → `test_review_main_refuses_main`, `test_review_main_refuses_a_card_worktree`.

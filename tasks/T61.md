## T61. Gate check for files at the repository root

Issue: #71.

Needs: nothing.

Spec: [AGENTS.md, Card-flow adapter](../AGENTS.md#card-flow-adapter), the `Gate.` item: a changed package without an entry in `bin/gate-checks.json` fails the gate. `bin/gate.py`'s `package_of` maps a changed file at the repository root that is not Markdown (for example `core-exceptions.json`) to the key `.`, and `.` has no entry, so this branch's change of `core-exceptions.json` fails the gate with `gate: .: no checks defined`. The gate runs an entry's `run` through the shell, in `cwd` relative to the repository root, and adds `env` with `setdefault`. [SOURCE-OWNERSHIP.md](../SOURCE-OWNERSHIP.md), "Coreの例外": `core-exceptions.json` is checked with `bin/check-core-separation.py --core <Core checkout>`.

Files: `bin/gate-checks.json`, `bin/test_gate.py`.

The lead creates the card worktree `reports/worktrees/T61` on branch `card/T61` from `issue/71-core-follow`; work there.

### Rules

1. Add exactly one key, `.`, to the top-level object of `bin/gate-checks.json`, with exactly one check object:
   - `"cwd": "."`
   - `"run": "python3 bin/check-core-separation.py --core \"$DSH_UPSTREAM_ROOT\""` (in the JSON file the two inner quotes are escaped as shown)
   - `"env": {"DSH_UPSTREAM_ROOT": "/data/softwares/deepseek-harness"}`
2. Keep the keys in byte order (the order `sorted()` gives in Python), so `.` becomes the first key. Keep the file's format: two-space indentation, `"cwd"` before `"run"` before `"env"`, a final newline. Change no other key.
3. In `bin/test_gate.py`, `RepositoryChecksTest.test_repository_checks_file_is_valid` lists the expected keys. Add `'.'` to that list, and change nothing else in that file.
4. Do not change any other file. Run the gate with `DSH_UPSTREAM_ROOT` unset or set to `/data/softwares/deepseek-harness`.
5. The check only reads the Core checkout through `git`; it writes nothing. It follows the live Core on purpose: when the live Core moves away from the approved base and the check fails, that is a finding to report, not a sandbox failure.
6. This card adds no guard code, so it has no `Must fail without:` line.
